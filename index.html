概要・学習方法、制限行為能力者

2. 制限行為能力者とは

判断能力がない・不十分な人を民法が保護する制度。未成年者・成年被後見人・被保佐人・被補助人の4類型で、一定の契約等を取り消すことができる。

4. 保護者の権利と取消権

  • 保護者の人数に制限はなく、法人が保護者に選任されることもある。
  • 取消しができる場合、本人のほか、同意権を有する保護者も取り消せる。
  • 相手方が、本人が制限行為能力者であることについて善意無過失でも、本人・保護者は取消しを主張できる（制限行為能力者保護が優先）。

5. 家庭裁判所の許可（居住用財産の処分）

成年後見人が成年被後見人の居住用財産を処分（売却、抵当権設定、賃貸、賃貸借の解除）するには家庭裁判所の許可が必要。勝手に住まいを処分されると本人の精神上の障害が悪化するおそれがあるため。

6. 制限行為能力者の詐術

行為能力者であると信じさせるために相手方に詐術を用いたときは、その行為を取り消せない。

代理

1. 代理の基本と復代理

代理人が本人の代わりに契約等をすると、効果は本人に帰属する。

  • 復代理：代理人がさらに代理人（復代理人）を選ぶこと。復代理人の権限は代理人と同じで、本人に対して代理人と同一の権利義務を負う。代理人の代理権が消滅すれば復代理権も消滅。
  • 任意代理での復代理人の選任は、本人の許諾があるとき、またはやむを得ない事由があるときに限る。

2. 自己契約・双方代理・代理権の濫用

行為扱い
自己契約・双方代理原則禁止（無権代理とみなす）。例外：債務の履行（契約後の移転登記など）・本人の許諾がある行為
代理権の濫用代理権の範囲内で自己・第三者の利益を図る行為。原則有効だが、相手方が目的を知り・知ることができたときは無権代理とみなす

3. 代理権の消滅（任意代理）

本人側代理人側
死亡／破産死亡／破産／後見開始の審判
ひっかけ
本人の後見開始では代理権は消滅しない。代理人側だけ。委任の終了事由（第10章）と同じ組合せ。

4. 無権代理

代理権がないのに代理行為をすると、本人に効果は帰属しない。ただし本人が追認すれば契約時にさかのぼって有効。

第1部 権利関係 ／ 第4章

時効

1. 取得時効

占有開始時の状態必要な期間共通要件
善意無過失10年所有の意思をもって、平穏かつ公然に占有
悪意または善意有過失20年
  • 占有開始時に善意無過失なら、途中で悪意になっても10年で完成。
  • 所有の意思：「これは私の物だ」という意思。買主の占有は通常あり。賃借人には所有の意思がないので何年占有しても時効取得しない。
  • 自己占有と代理占有：他人に占有させている（賃貸等）期間も合算できる（Bが8年占有＋Cに2年賃貸＝10年）。
  • 占有の承継：売買・相続で前の占有者の期間と善意無過失を引き継げる（善意無過失のBが8年占有後に悪意のCへ売却 → Cはあと2年で完成）。
  • 取得できる権利：所有権のほか地上権・地役権・不動産賃借権なども。

2. 消滅時効

  • 債権者が権利を行使できることを知った時から5年、または権利を行使できる時から10年（人の生命・身体の侵害による損害賠償請求権は20年）。
  • 所有権は消滅時効にかからない。

3. 完成猶予と更新

完成猶予
時効の完成を一時的にストップ（期間は進んだまま）
vs
更新
進んだ期間をリセットしてゼロから再スタート

第1部 権利関係 ／ 第5章

共有、区分所有法

1. 共有の持分

  • 持分は定めがなければ平等（実際は出資額で決めることが多い：別荘700万円をA400・B200・C100で購入 → 4/7・2/7・1/7）。
  • 持分は他の共有者の同意なく自由に処分（譲渡・放棄・抵当権設定）できる。
  • ①持分の放棄 ②共有者が死亡し相続人・特別縁故者がいない → その持分は他の共有者に帰属。
  • 各共有者は持分に応じて共有物全体を使用できる（善管注意義務あり）。持分を超える使用の対価は他の共有者に償還。
  • 管理費等は持分に応じて負担。1年以上滞納した共有者の持分は、他の共有者が相当の償金を払って取得できる。

2. 共有物の管理・変更

行為要件具体例
保存行為単独で可修繕、第三者への妨害排除請求、持分に基づく損害賠償請求（自己の持分割合のみ）
管理行為・軽微な変更持分価格の過半数（頭数ではない）短期賃借権の設定（土地5年以下・建物3年以下）、賃貸借契約の解除、管理者の選任・解任、形状・効用の著しい変更を伴わない変更
重大な変更全員の同意地目変更（農地→宅地）、売却、抵当権設定

別荘の例ではAの持分が4/7なので、Aが賛成すればB・Cが反対でも管理行為ができる。

3. 共有物の分割

  • 各共有者はいつでも分割請求できる。分割禁止特約は全員の合意で最長5年（更新可、更新後も最長5年）。
  • 方法：①現物分割 ②代金分割（売って代金を分ける） ③賠償分割（1人が取得し他に金銭で賠償）。協議が調わなければ裁判所に請求。裁判所は現物・賠償分割ができないとき等に競売を命じられる。

4. 区分所有法：用語

用語内容
専有部分各部屋（101号室など）。床面積は壁等の内側線で囲まれた部分の水平投影面積
区分所有権・区分所有者各部屋の所有権・そのオーナー
共用部分法定共用部分（階段・EV・廊下）と規約共用部分（集会室・管理人室）。全員の共有。一部共用部分（店舗専用の出入口等）はそれを共用する区分所有者の共有。持分は専有部分の床面積割合（規約で別段の定め可）
敷地利用権所有権・地上権・賃借権。専有部分と分離して処分できない（規約で別段の定め可）
管理組合区分所有者全員で構成。当然に組合員になる
管理者管理組合の代表。区分所有者以外（個人・法人）でも可

項目ルール

抵当権

1. 用語

用語内容
被担保債権抵当権によって担保される債権（貸したお金）
抵当権者抵当権を有する債権者
抵当権設定者自分の不動産に抵当権を設定する者
物上保証人他人の債務のために自分の不動産に抵当権を設定する者

抵当権者は競売代金から他の債権者に先立って優先的に回収できる。

2. 効力の及ぶ範囲

対象効力例
付合物（独立性なし）及ぶ雨戸・ガラス戸、立木・庭石
従物（独立性あり）及ぶ畳、石灯篭、地下タンク・洗車機
従たる権利及ぶ敷地賃借権（借地権）
土地と建物及ばない土地のみに設定した抵当権は建物に及ばない（別個の不動産）

3. 性質

  • 付従性：債権が主人公、抵当権は付き人。債権が成立しなければ抵当権も成立せず、債権が消滅すれば抵当権も消滅。
  • 物上代位性：目的物の滅失で生じた保険金・売買代金・損害賠償請求権・賃料等にも効力が及ぶ。ただし払渡し前に差押えが必要。

4. 第三取得者の保護

代価弁済
抵当権者の請求に応じて第三取得者が代価を弁済すると抵当権消滅
vs
抵当権消滅請求
第三取得者から抵当権者全員に金額を提示して消滅を請求。主たる債務者・保証人は使えない。競売による差押えの前に請求

5. 抵当不動産の賃貸借

抵当権設定登記後の賃借人は、原則として競売の買受人に対抗できず立ち退く必要がある。借主保護の規定が2つ。

  • 同意の登記：賃借権を登記し、先順位の抵当権者全員の同意とその同意の登記があれば対抗できる（利害関係人の承諾も必要）。
  • 引渡しの猶予：建物の賃借人は買受けの時から6か月は引き渡さなくてよい。

6. 法定地上権と一括競売

法定地上権（建物を残す）
要件：①1番抵当権設定当時、土地上に建物が存在 ②その当時同一人が土地・建物を所有 ③競売で土地と建物の所有者が別々になった
効果：建物のために法律上当然に地上権が発生
一括競売（更地に抵当権後に建築）
要件：①設定当時更地 ②設定後に建物を築造
効果：抵当権者は土地と建物を一括して競売できる。ただし優先弁済を受けられるのは土地の代金のみ

保証、連帯債務

1. 保証の基本

  • 保証契約は債権者と保証人の間で締結。主たる債務者の委託がなくても、意思に反しても有効。必ず書面（電磁的記録可）でする。
  • 保証債務の範囲は元本・利息・違約金・損害賠償など。保証人は保証債務についてのみ違約金・損害賠償額を約定できる。弁済したら主たる債務者に求償できる。

2. 保証債務の性質

付従性（川の流れ：上から下へ）

  • 主たる債務がなければ保証債務も成立せず、消滅すれば消滅。主たる債務者に生じた事由は保証人に及ぶが、逆は及ばない。
  • 例外（保証人に及ばない）：①保証契約後に主たる債務者の負担が加重された ②主たる債務者が債務を増額した。

補充性（保証人は2番手）

抗弁権内容
催告の抗弁権「まず債務者に催告しろ」と拒める。債務者が破産手続開始決定を受けたとき・行方不明のときは使えない
検索の抗弁権①債務者に弁済の資力がある（一部でも可） ②執行が容易 を証明して「債務者の財産から取れ」と拒める

3. 共同保証と連帯保証

一般保証連帯保証
補充性（催告・検索の抗弁権）ありなし（いきなり請求されたら払う）
分別の利益（共同保証で頭数割り）ありなし（連帯保証人3人・主債務600万円 → 各600万円）

共同保証人が自己の負担部分を超えて弁済したら、他の共同保証人にも負担部分に応じて求償できる。

4. 連帯債務

  • 原則は分割債務（100万円の車をB・Cが買えばAは各50万円しか請求できない）。連帯債務なら債権者は誰にでも全額を同時にも順次にも請求できる。
  • 負担部分：定めがなければ平等。求償権：弁済した額が自己の負担部分を超えるかどうかにかかわらず、他の連帯債務者に負担部分に応じて求償できる（Bが500万円弁済 → Cに250万円求償）。
相対効（他に影響なし）絶対効（他にも影響）
請求（Bへの裁判上の請求でCの時効は猶予されない）／承認／時効の完成／債務の免除相殺（Bが反対債権で相殺→Cの債務も消滅）／更改／混同（Bが債権者Aを相続）／弁済

1. 債権譲渡

  • 債権は第三者に譲渡でき、将来債権も譲渡可。譲渡人Aと譲受人Cの合意で足り、債務者Bの承諾は不要。
  • 譲渡制限の意思表示：特約に反する譲渡も原則有効。ただし譲受人が悪意・善意重過失なら、債務者は履行を拒絶でき、譲渡人への弁済等をもって対抗できる。
対抗の相手対抗要件
債務者①譲渡人から債務者への通知 または ②債務者の承諾（承諾の相手は譲渡人・譲受人どちらでも可）
債務者以外の第三者（二重譲渡）確定日付のある証書（公正証書・内容証明郵便）による通知または承諾。先に備えた方が勝ち。双方が確定日付ある通知なら先に債務者に届いた方が勝ち

2. 債務不履行

履行遅滞できるのに期日を過ぎても履行しない
履行不能履行が不可能（後発的・原始的不能）。取引上の社会通念で判断
→
債権者は損害賠償請求と契約の解除ができる
  • 損害賠償：金銭賠償が原則。債務者に帰責事由がなければ責任なし。損害賠償額の予定は契約と同時でなくてもよい。
  • 解除：債務者の帰責事由は不要。ただし債権者の帰責事由による不履行なら解除不可。
解除の方法内容
催告による解除（原則）相当の期間を定めて催告し、期間内に履行がなければ解除。期間経過時の不履行が軽微なら解除不可
催告によらない解除①全部の履行不能 ②履行拒絶の意思を明確に表示 ③催告しても目的達成の見込みがないことが明らか など → 直ちに解除
解除の効果原状回復義務（契約前の状態に戻す）＋損害があれば損害賠償請求も可

3. 危険負担

契約後・引渡し前に、売主・買主双方に帰責事由なく（不可抗力で）建物が滅失した場合：買主の代金債務は消滅しないが、買主は支払いを拒絶でき、売主の引渡債務の不履行を理由に解除もできる。

1. 弁済

制度内容
代物弁済本来の給付に代えて他の給付（1,000万円の代わりに同額相当の高級車）。当事者の契約に基づく
弁済供託法務局等に預けると弁済と同じ効果。①債権者の受領拒否 ②受領不能（行方不明） ③債権者不確知
第三者の弁済正当な利益を有しない者（友人等）：債務者・債権者の意思に反しないことが必要
正当な利益を有する者（物上保証人・第三取得者・借地上の建物賃借人）：意思に反しても可
共通：当事者が第三者弁済を禁止・制限していないこと
受領権者以外への弁済原則無効。ただし取引上の社会通念に照らし受領権者の外観を有する者（通帳と届出印の持参人、受取証書の持参人）に善意無過失で弁済すれば有効

2. 相殺

互いに同種の金銭債務を負うとき、一方の意思表示で対当額を消滅させる。言い出した側の債権が自働債権、言われた側の債権が受働債権。

相殺できないケース内容
①不法行為等による債権悪意による不法行為・生命身体の侵害による損害賠償債務の債務者（加害者）からは相殺できない。被害者側からは可
②差押え後に取得した債権差押え後に取得した債権による相殺は差押債権者に対抗できない。差押え前に取得した債権なら対抗できる

3. 売主の義務と契約不適合責任

  • 売主は買主に登記等の対抗要件を備えさせる義務を負う。他人物売買も有効で、売主は権利を取得して移転する義務を負う。
  • 目的物が種類・品質・数量に関して、または権利に関して契約内容に適合しないとき、買主は次の4つができる。
買主の権利内容
①追完請求修補・代替物・不足分の引渡し。売主は買主に不相当な負担でなければ別の方法で追完できる。買主に帰責事由があれば不可
②代金減額請求相当期間を定めて追完を催告し、追完がなければ不適合の程度に応じて減額。催告不要：追完不能／追完拒絶の明示／見込みがないことが明らか。買主に帰責事由があれば不可
③損害賠償請求・④解除債務不履行の規定による
不適合の種類通知期間消滅時効
種類・品質買主が知った時から1年以内に通知しないと権利行使不可。売主が引渡し時に悪意・善意重過失なら通知期間の制限なし知った時から5年／引渡しから10年
数量・権利通知期間なし

担保責任を負わない特約：有効。ただし売主が知りながら告げなかった事実については責任を免れない。

4. 手付（解約手付）

  • 交付された手付は原則解約手付。契約締結後に交付しても有効。
  • 買主は放棄、売主は倍額を現実に提供して解除。相手方が履行に着手するまで可能（自分が着手していても相手が未着手なら解除できる）。
  • 手付解除では損害賠償請求はできない。
履行の着手の例
売主の履行：引渡し・移転登記。買主の履行：代金支払。売主Aが着手すると買主Bは手付放棄解除ができなくなるが、Aからの倍返し解除はできる（逆も同様）。
第1部 権利関係 ／ 第10章

請負、委任、不法行為

1. 請負

  • 請負人が仕事を完成させ、注文者が報酬を払う契約（建築・リフォーム）。報酬は目的物の引渡しと同時履行。
  • 担保責任：売買と同様に①追完請求 ②報酬減額請求 ③損害賠償請求 ④解除。種類・品質の不適合は注文者が知った時から1年以内に通知（請負人が悪意・善意重過失なら制限なし）。担保責任を負わない特約は有効だが、知りながら告げなかった事実は免れない。
  • 解除：注文者は仕事完成前ならいつでも損害を賠償して解除できる。請負人は注文者が破産手続開始決定を受けたとき解除できるが、完成後は不可。

2. 委任

受任者の権利受任者の義務
・報酬請求権：特約がなければ無報酬。後払いが原則。委任者に帰責事由なく履行できなくなったとき・中途で終了したときは履行の割合に応じて請求可
・費用前払請求権
・費用償還請求権（支出日以後の利息も）
・損害賠償請求権（過失なく損害を受けたとき）		・善管注意義務（報酬の有無にかかわらず）
・報告義務（請求があればいつでも／終了後遅滞なく）
・引渡義務（受領した金銭・物）
  • 復委任：原則不可。委任者の許諾またはやむを得ない事由があれば可。
  • 解除：各当事者がいつでも解除できる。相手方に不利な時期の解除等は損害賠償（やむを得ない事由があれば不要）。
  • 終了事由：委任者の死亡・破産／受任者の死亡・破産・後見開始の審判。終了後も急迫の事情があれば受任者は必要な処分をする。

3. 一般不法行為

  • 故意・過失で他人の権利を侵害した加害者は損害賠償義務を負う。損害は財産的損害＋精神的損害（慰謝料）。損害賠償請求権は相続の対象。
  • 期間制限：損害および加害者を知った時から3年（生命・身体の侵害は5年）／不法行為の時から20年。
  • 過失相殺：被害者に過失があれば裁判所は賠償額を減額できる。
  • 履行遅滞：加害者の賠償債務は損害発生と同時に遅滞（催告不要で遅延利息が発生）。

4. 特殊不法行為

類型内容
共同不法行為加害者各自が連帯して全額の賠償責任。被害者は全員に全額請求できる
使用者責任被用者が事業の執行について他人に損害を与えたら使用者も責任を負う。事業の執行かは行為の外形で客観的に判断（勤務時間外でもスーツで営業車なら該当）。被害者が悪意・善意重過失なら使用者は免責。使用者の被用者への求償は信義則上相当な限度
土地工作物責任一次的：占有者（過失責任。必要な注意をしていれば免責）→ 二次的：所有者（無過失責任）。賠償した者は原因に責任のある者（手抜き工事の業者等）に求償できる

第2部 宅建業法 ／ 第20章

営業保証金、保証協会

1. 営業保証金の仕組み

宅建業者と取引した相手方が損害を受けたとき、業者に資力がないと弁済されない。そこであらかじめ供託所（法務局）にお金を預けておく制度。

2. 供託の手続き

項目内容
供託場所主たる事務所（本店）の最寄りの供託所に、全事務所分をまとめて供託
供託金額本店 1,000万円＋支店1か所につき 500万円
有価証券での供託可。国債＝額面100%、地方債・政府保証債＝90%、その他省令で定める有価証券＝80%で評価
例
本店＋支店2か所 → 2,000万円。地方債証券2,000万円を供託すると評価額は1,800万円で不足。

  • 免許した日から3か月以内に届出がない → 免許権者は届出をすべき旨を催告しなければならない（義務）。
  • 催告到達から1か月以内に届出がない → 免許を取り消すことができる（任意）。
  • 事務所を増設したら1か所500万円を本店最寄りの供託所に追加供託し、届出をした後でなければ新事務所で営業できない。

3. 保管替え等（本店移転で最寄り供託所が変わる場合）

金銭のみで供託しているとき
遅滞なく費用を予納して、現在の供託所に保管替えを請求しなければならない。
有価証券を含むとき
遅滞なく新供託所に新たに供託し、その後に従前の営業保証金を取り戻す（二重供託の期間が生じる）。

4. 還付と不足額の供託

  • 還付を受けられるのは、宅建業に関して取引をした者（損害を受けた相手方）に限る。広告業者の広告料債権などは対象外。宅建業者は還付対象から除外（一般消費者保護が目的）。
  • 還付されて不足が生じたら、免許権者から通知書の送付を受けた日から2週間以内に不足額を供託し、供託した日から2週間以内に免許権者へ届出。

⑥本店移転で供託所が変わった（有価証券パターン） ⑦保証協会の社員になった公告不要で直ちに取戻し可

正当な事由がある場合を除き、業務上取り扱った秘密を漏らしてはならない。宅建業を営まなくなった後も同様。正当な事由の例：裁判の証人になる場合、取引相手に真実を告げなければならない場合、依頼者の承諾がある場合。

2. 担保責任の特約の制限

民法では「売主は担保責任を負わない」特約も有効。宅建業法は、業者が自ら売主の場合、種類・品質の契約不適合責任について民法より買主に不利な特約を禁止。

民法の原則
買主は不適合を知った時から1年以内に売主に通知
例外
宅建業法が許す唯一の例外
通知期間を引渡しの日から2年以上とする特約は有効

違反する特約は無効となり、民法の規定が適用される。

特約の判定
  • 「引渡しから1年間担保責任を負う」 → 無効（民法が適用され、知った時から1年以内の通知でOK）
  • 「契約の解除には応じない」 → 無効

3. 他人物売買等の制限

民法では他人物売買も有効だが、宅建業法は、自己の所有に属しない物件について業者が自ら売主となる売買契約・予約を原則禁止。

  • 取得契約は予約でもOK。ただし停止条件付きはNG（確実に取得できる保証がない）。
  • 取得契約があれば、引渡し・移転登記・代金支払いが未済でもOK。

4. 損害賠償額の予定・違約金の制限

民法宅建業法（自ら売主）
定めあり額に制限なし（代金の60%でも可）予定額＋違約金の合算が代金の2割まで。超える部分のみ無効
定めなし実損額を請求実損額を請求（20%制限なし）

民法の復習：予定は契約と同時でなくてもよい。予定した以上、実損が異なっても増減を主張できない。

8種制限②　クーリング・オフ、割賦販売、所有権留保、手付の額、手付金等の保全措置

1. クーリング・オフ（申込みの撤回・契約の解除）

訪問販売や喫茶店・ホテルのロビー等で安易に申込みをした一般消費者を守る制度。「場所」→「場面」の順に判定する。

C・Oができない「場所」（事務所等）

  1. 事務所（本店・支店等）
  2. 宅地・建物の分譲を行う案内所（モデルルーム等）。土地に定着するものに限る → テント張りの案内所は該当しない（C・Oできる）
  3. 相手方（申込者・買主）が申し出た場合の、相手方の自宅・勤務先（業者が申し出て自宅へ行った場合はC・O可）
  • 売主業者から代理・媒介を依頼された業者が設置した①②も「事務所等」。
  • 申込み場所と契約場所が異なるときは申込み場所で判断（例：事務所で申込み、レストランで契約 → 不可）。

C・Oができない「場面」

  1. 業者からC・Oできる旨・方法を書面で告げられた日から起算して8日を経過したとき（口頭で告げても起算しない）
  2. 相手方が引渡しを受け、かつ代金の全部を支払ったとき（両方そろって初めて不可）

方法・効果・特約

  • 方法：相手方がC・Oする旨の書面を発した時に効力発生（発信主義）。届いていなくても発信の証拠があればOK。
  • 効果：業者は損害賠償・違約金を請求できず、受領済みの手付金等は速やかに全額返還。
  • 特約：相手方に不利な特約はすべて無効（例：「C・O期間は5日」）。

2. 割賦販売契約の解除等の制限

割賦販売＝業者が代金を分割で受け取る契約。賦払金の支払が遅れても、30日以上の相当の期間を定めて書面で催告し、その期間内に履行がないときでなければ、解除や残額の一括請求はできない。

3. 所有権留保の禁止

原則
割賦販売では、物件を引き渡すまでに登記等の売主の義務を履行しなければならない（所有権留保の禁止）
例外
留保できる場合
引渡しまでに受領した額が代金の10分の3以下のとき

引渡し後も業者が登記に協力せず所有権を留めると、業者の破産時に買主が損害を受けるため。

4. 手付の額の制限と性質

民法の解約手付（復習）
買主は手付を放棄、売主は倍額を現実に提供して解除できる。相手方が履行に着手するまで。手付解除の場合、損害賠償請求はできない。
  • 性質の制限：業者が自ら売主の売買で受領する手付は、名目を問わず解約手付とみなされる。
  • 額の制限：代金の2割を超える手付は受領できない。
  • これらに反して買主に不利な特約は無効。
特約の判定
  • 「売主は買主が履行に着手した後でも倍返しで解除できる」 → 無効（買主に不利）
  • 「買主は手付の半額を放棄すれば解除できる」 → 有効（買主に有利）

5. 手付金等の保全措置

引渡し前に受領した代金等が、業者の破産で返ってこなくなるのを防ぐ制度。原則として保全措置を講じなければ手付金等を受領できない。

  • 手付金等：契約締結日以後、引渡し前に支払われ、代金に充当される金銭（手付金・中間金など）。
  • 措置の種類：①保証委託契約（銀行等） ②保証保険契約（保険会社） ③手付金等寄託契約（指定保管機関）。未完成物件では①②のみ、完成物件は①〜③すべて可。
保全措置が不要な場合内容

完成物件：代金の10%以下かつ1,000万円以下
②登記済み買主が所有権の登記（移転・保存）を備えた場合

  2. 一方からの媒介限度額：5,000万円×3%＋6万円＝156万円 → ×1.1＝171万6,000円
  3. 双方媒介なら合計 343万2,000円。代理なら一方から 343万2,000円（156万×2×1.1）。
  4. Aが媒介（Cから1）・Bが代理（Dから2）だと合計3になるため不可。合計は2以内。

国土利用計画法

1. 事後届出制度

地価高騰の抑制と合理的な土地利用のため、一定の土地取引に届出を義務づける。土地売買等の契約を締結したら、権利取得者が、契約締結日から2週間以内に、市町村長を経由して都道府県知事に届出。

契約締結
→
権利取得者が2週間以内に届出（市町村長経由→知事）
→
知事は届出から3週間以内に利用目的の変更を勧告できる
→
勧告に従わない → 公表できる（契約は有効）

2. 届出が必要な契約・不要な契約

土地売買等の契約に該当する（届出必要）該当しない（届出不要）
売買（予約を含む）、交換、対価のある賃借権・地上権の設定。停止条件付き契約も該当（条件成就時の届出は不要）抵当権設定、贈与、相続、遺贈、遺産分割、時効取得、担保権実行（競売）

3. 面積例外・その他の例外

区域届出不要となる面積（権利取得者の取得面積で判断）
市街化区域2,000㎡未満
市街化調整区域・区域区分の定めのない都市計画区域5,000㎡未満
都市計画区域外（準都市計画区域、都計外）10,000㎡未満

その他の例外：①当事者の一方または双方が国・地方公共団体等 ②農地法3条の許可を受ける場合 ③民事調停法による調停。

開発許可の面積と混同注意
開発許可：市街化区域1,000㎡／非線引き・準都計3,000㎡／都計外10,000㎡。国土法：市街化区域2,000㎡／調整区域・非線引き5,000㎡／都計外10,000㎡。

4. 届出事項・勧告・助言・罰則

  • 届出事項：当事者の氏名・住所、契約締結年月日、取得後の土地の利用目的、対価の額。
  • 勧告：知事は利用目的を審査し、変更を勧告できる（原則届出日から3週間以内）。従わなければ公表できるが、契約は有効。
  • 助言：利用目的について助言できる。助言に従わなくても公表されない。
  • 届出をしなかった場合：契約は有効。罰則：6月以下の拘禁刑または100万円以下の罰金。

5問免除の学習方法
学習量は多くないので9月から少しずつでも間に合う。土地・建物は範囲が膨大なので深入りしない。統計は最新データ（吉野塾のストアで8月上旬に無料配布予定）で学習する。

1. 住宅金融支援機構

民間金融機関をサポートして長期固定金利の住宅ローンを実現する（証券化支援業務）。民間が対応しにくい分野では直接融資を行う。

顧客
→
①銀行等が長期固定金利ローン（フラット35）を融資
→
②機構が債権を買い取り
→
③証券化（MBS）して投資家に販売
  • 金利や手数料は金融機関によって異なる。
  • 買取型の対象債権：新築の建設・購入、中古住宅の購入、付随する土地・借地権の取得、親族居住用住宅、購入に付随する改良、高齢者の居住性能向上のための改良。賃貸住宅は対象外。
  • ZEH・省エネ・耐震・バリアフリー等に優れた住宅は一定期間金利引下げ。
  • 高齢者向け返済特例：毎月は利息のみ、元金は死亡時に一括返済。
  • 直接融資（例外）：①災害復興建築物の建設・購入、被災建築物の補修 ②合理的土地利用建築物の建設・購入、マンション共用部分の改良 ③子育て家庭・高齢者家庭向け賃貸住宅の建設・改良 ④高齢者が自ら居住する住宅のバリアフリー改良 ⑤60歳以上の高齢者の部分的バリアフリー・ヒートショック対策・耐震改修（高齢者向け返済特例）。
  • 団体信用生命保険業務：死亡・重度障害時の保険金を債務の弁済に充当。

2. 景品表示法（不動産の表示に関する公正競争規約）

公正競争規約は業界の自主規制。以下は不動産業界のルール。

特定事項の明示義務

  1. 市街化調整区域の土地：「市街化調整区域。宅地の造成及び建物の建築はできません。」と明示（チラシ等は16ポイント以上）。
  2. 建築基準法上の道路に2m以上接していない土地：「再建築不可」または「建築不可」。
  3. 高圧電線路下の土地：その旨とおおむねの面積。建築禁止ならその旨も。
  4. 道路区域・都市計画施設の区域の土地：その旨。
  5. 工事を相当期間中断した新築住宅・マンション：着手時期と中断期間。

土地・建物

1. 土地

宅地に適している特徴
台地平らで周囲より高い。地盤が安定し災害に強い。農地・都市的利用も多い
丘陵なだらかな起伏。台地・丘陵の縁辺部は豪雨時のがけ崩れに注意
段丘河岸・海岸の階段状地形。砂礫・硬粘土で地下水位が深い
自然堤防河川の氾濫で川の両側にできた微高地。砂・小礫で排水良好、地盤も比較的良い
宅地に適していない特徴
旧河道かつての流路。泥土で排水が悪く軟弱
後背低地（後背湿地）自然堤防の背後の低湿地。軟弱。水田利用が多い
三角州河口付近の軟弱地盤
扇状地砂礫で地盤は良好だが、谷出口は土石流の危険が高い
干拓地排水が悪く軟弱。海面より低いことが多く津波に注意
埋立地海面より高いので干拓地より安全
  • 等高線：間隔が密＝急傾斜、疎＝緩やか。乱れている部分は過去の崩壊の可能性。山頂に向かって高い方に弧を描く部分が谷、山頂から張り出す部分が尾根。
  • 地すべり地：地下水の影響で斜面が滑る。地すべり地形は棚田等の水田に利用される。
  • 液状化：地震で地下水位の高い砂地盤が液体状になる。

2. 建物

構造特徴
木造①乾燥して含水率が小さいほど強度大 ②辺材は心材より腐朽しやすく耐久性小 ③圧縮強度は繊維直角方向より繊維方向が大
・枠組壁工法（ツーバイフォー）：壁式で耐震性に優れる
・集成木材工法：ドーム・体育館など大型建築に用いる
鉄骨造（S造）不燃だが火熱で耐力が落ちるため耐火構造には耐火材料で被覆。自重が軽く靱性が大きく高層向き。炭素含有量が多いと硬く伸びが減るので炭素の少ない鋼を使う
鉄筋コンクリート造（RC造）鉄筋とコンクリートの長所を生かし短所を補う。中性化は耐久性に影響。耐火・耐久・耐震・耐風に優れる。コンクリートの引張強度は圧縮強度より小さい
鉄骨鉄筋コンクリート造（SRC造）S造の靱性＋RC造の耐火性・耐久性。RC造より靱性・強度に優れ高層建築に使用
地震対策の構造仕組み
耐震構造柱・はり・耐震壁で剛性を高めて耐える
免震構造下部構造と上部構造の間に積層ゴム等を設置して揺れを減らす
制震構造制震ダンパー等で揺れを制御
