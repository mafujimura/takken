第1部 宅建業法 ／ 第1章

概要・学習方法、宅建業・宅建業者の定義

出題：宅建業法19問＋住宅瑕疵担保履行法1問＝20問　目標18点

1. 学習方法の3原則

宅建業法で高得点を取る考え方
  1. 似たルールを対比して整理する：宅建業者と宅建士、営業保証金と保証協会、35条書面と37条書面など。中途半端に覚えると両方とも曖昧になり失点する。
  2. 満点を狙う気持ちで：範囲が狭く難度も低い科目なので、弱点分野は早めに潰す。
  3. 3大書面と8種制限に時間をかける：媒介契約書・重要事項説明書・37条書面と8種制限で、年によっては11問前後出る。

2. 宅建業とは（宅地＋建物＋取引＋業）

「宅地建物取引業」に該当する行為をするには免許が必要。無免許営業や名義貸し（自己の名義で他人に宅建業を営ませる行為）は禁止。宅建業に該当しない行為には、そもそも宅建業法が適用されない。

4要素すべてを満たして初めて「宅建業」。1つでも欠ければ免許不要。

宅地の定義

次の①②のどちらかに当たれば宅地。

  1. 建物の敷地に供せられる土地：現に建物が建っている土地だけでなく、将来建物を建てる予定の土地も含む（現在の地目が農地でも宅地）。
  2. 用途地域内の土地：道路・公園・河川・広場・水路を除き、すべて宅地。
用途地域「外」用途地域「内」
①現在建物がある土地 ②建築予定の土地宅地宅地
上記以外の土地（農地・山林など）宅地ではない原則 宅地（道路・公園・河川・広場・水路を除く）

建物の定義

屋根・壁・柱があるものは建物。アパートやマンションの一室、倉庫も建物に当たる。ソーラーパネルや建築資材置場は建物ではない。

投資用マンションのオーナーになる、アパート経営をする、サブリース（転貸）をする——いずれも免許不要。

取引に該当しない例：マンション管理業、マンション建設業、不動産賃貸業、転貸（サブリース）、宅地造成業。いずれも宅建業ではないので免許不要。

業の定義

不特定多数の相手方に対し、反復継続して取引を行うこと（利益を追求する行為）。

具体例で判定
  1. Aが所有する用途地域内の農地を区画割りして分譲する → 宅建業に該当（用途地域内の土地は原則宅地）。
  2. A所有の商業ビルを賃借するBが、フロアごとに不特定多数へ反復継続して転貸する → A・Bともに該当しない（自ら貸借・転貸は取引ではない）。
  3. Aが競売で取得した宅地を10区画に分割し、宅建業者に販売代理を依頼して分譲する → Aは宅建業に該当（Aに免許が必要）。本人が宅建業をしている以上、代理・媒介を業者に頼んでも本人の免許は必要。

3. 宅建業者と特則

免許を取得して宅建業を営む者。個人でも法人でもなれる。

区分扱い
国・地方公共団体・都市再生機構・地方住宅供給公社 等宅建業法が適用されないため、免許なしで宅建業ができる
信託会社・信託銀行 等免許不要。ただし宅建業を営む旨を国土交通大臣に届出
みなし宅建業者個人業者の死亡・法人の合併消滅・免許失効（廃業等）の場合でも、取引を結了する目的の範囲内では宅建業者とみなされる。免許の効力は一代限りで承継はできない
みなし宅建業者の具体例
  • 個人業者Aが死亡し相続人Bが相続 → BはAが締結済みの売買契約の物件引渡しはできる。
  • 法人業者Aが宅建業者でない法人Bに吸収合併され消滅 → BはAの締結済み契約の引渡しができる。

第1部 宅建業法 ／ 第4章

営業保証金、保証協会

1. 営業保証金の仕組み

宅建業者と取引した相手方が損害を受けたとき、業者に資力がないと弁済されない。そこであらかじめ供託所（法務局）にお金を預けておく制度。

2. 供託の手続き

項目内容
供託場所主たる事務所（本店）の最寄りの供託所に、全事務所分をまとめて供託
供託金額本店 1,000万円＋支店1か所につき 500万円
有価証券での供託可。国債＝額面100%、地方債・政府保証債＝90%、その他省令で定める有価証券＝80%で評価
例
本店＋支店2か所 → 2,000万円。地方債証券2,000万円を供託すると評価額は1,800万円で不足。

営業開始までの流れと届出をしない場合の措置

①免許取得
→
②保証金を供託
→
③供託した旨を免許権者に届出
→
④営業開始
  • 免許した日から3か月以内に届出がない → 免許権者は届出をすべき旨を催告しなければならない（義務）。
  • 催告到達から1か月以内に届出がない → 免許を取り消すことができる（任意）。
  • 事務所を増設したら1か所500万円を本店最寄りの供託所に追加供託し、届出をした後でなければ新事務所で営業できない。

3. 保管替え等（本店移転で最寄り供託所が変わる場合）

金銭のみで供託しているとき
遅滞なく費用を予納して、現在の供託所に保管替えを請求しなければならない。
有価証券を含むとき
遅滞なく新供託所に新たに供託し、その後に従前の営業保証金を取り戻す（二重供託の期間が生じる）。

4. 還付と不足額の供託

  • 還付を受けられるのは、宅建業に関して取引をした者（損害を受けた相手方）に限る。広告業者の広告料債権などは対象外。宅建業者は還付対象から除外（一般消費者保護が目的）。
  • 還付されて不足が生じたら、免許権者から通知書の送付を受けた日から2週間以内に不足額を供託し、供託した日から2週間以内に免許権者へ届出。

5. 取戻し

取戻し事由公告
①免許の有効期間満了 ②廃業等の届出 ③免許取消処分 ④一部事務所の廃止による超過 ⑤個人業者の死亡・法人の合併消滅還付請求権者に6か月を下らない期間内に申し出るよう公告し、申出がなければ取戻し可。公告したら遅滞なく免許権者に届出
⑥本店移転で供託所が変わった（有価証券パターン） ⑦保証協会の社員になった公告不要で直ちに取戻し可

6. 保証協会

保証協会（現在は全国宅地建物取引業保証協会と不動産保証協会の2つ）に加入すれば、営業保証金の供託が免除される。社員は宅建業者のみ。弁済業務が重要任務。

試験のポイント：宅建業者は供託所と直接やり取りしない。間に保証協会が入る。

3. 他人物売買等の制限

民法では他人物売買も有効だが、宅建業法は、自己の所有に属しない物件について業者が自ら売主となる売買契約・予約を原則禁止。

  • 取得契約は予約でもOK。ただし停止条件付きはNG（確実に取得できる保証がない）。
  • 取得契約があれば、引渡し・移転登記・代金支払いが未済でもOK。

4. 損害賠償額の予定・違約金の制限

民法宅建業法（自ら売主）
定めあり額に制限なし（代金の60%でも可）予定額＋違約金の合算が代金の2割まで。超える部分のみ無効
定めなし実損額を請求実損額を請求（20%制限なし）

民法の復習：予定は契約と同時でなくてもよい。予定した以上、実損が異なっても増減を主張できない。

第1部 宅建業法 ／ 第9章

8種制限②　クーリング・オフ、割賦販売、所有権留保、手付の額、手付金等の保全措置

1. クーリング・オフ（申込みの撤回・契約の解除）

訪問販売や喫茶店・ホテルのロビー等で安易に申込みをした一般消費者を守る制度。「場所」→「場面」の順に判定する。

C・Oができない「場所」（事務所等）

  1. 事務所（本店・支店等）
  2. 宅地・建物の分譲を行う案内所（モデルルーム等）。土地に定着するものに限る → テント張りの案内所は該当しない（C・Oできる）
  3. 相手方（申込者・買主）が申し出た場合の、相手方の自宅・勤務先（業者が申し出て自宅へ行った場合はC・O可）
  • 売主業者から代理・媒介を依頼された業者が設置した①②も「事務所等」。
  • 申込み場所と契約場所が異なるときは申込み場所で判断（例：事務所で申込み、レストランで契約 → 不可）。

C・Oができない「場面」

  1. 業者からC・Oできる旨・方法を書面で告げられた日から起算して8日を経過したとき（口頭で告げても起算しない）
  2. 相手方が引渡しを受け、かつ代金の全部を支払ったとき（両方そろって初めて不可）

方法・効果・特約

  • 方法：相手方がC・Oする旨の書面を発した時に効力発生（発信主義）。届いていなくても発信の証拠があればOK。
  • 効果：業者は損害賠償・違約金を請求できず、受領済みの手付金等は速やかに全額返還。
  • 特約：相手方に不利な特約はすべて無効（例：「C・O期間は5日」）。

2. 割賦販売契約の解除等の制限

割賦販売＝業者が代金を分割で受け取る契約。賦払金の支払が遅れても、30日以上の相当の期間を定めて書面で催告し、その期間内に履行がないときでなければ、解除や残額の一括請求はできない。

3. 所有権留保の禁止

原則
割賦販売では、物件を引き渡すまでに登記等の売主の義務を履行しなければならない（所有権留保の禁止）
例外
留保できる場合
引渡しまでに受領した額が代金の10分の3以下のとき

引渡し後も業者が登記に協力せず所有権を留めると、業者の破産時に買主が損害を受けるため。

4. 手付の額の制限と性質

民法の解約手付（復習）
買主は手付を放棄、売主は倍額を現実に提供して解除できる。相手方が履行に着手するまで。手付解除の場合、損害賠償請求はできない。
  • 性質の制限：業者が自ら売主の売買で受領する手付は、名目を問わず解約手付とみなされる。
  • 額の制限：代金の2割を超える手付は受領できない。
  • これらに反して買主に不利な特約は無効。
特約の判定
  • 「売主は買主が履行に着手した後でも倍返しで解除できる」 → 無効（買主に不利）
  • 「買主は手付の半額を放棄すれば解除できる」 → 有効（買主に有利）

5. 手付金等の保全措置

引渡し前に受領した代金等が、業者の破産で返ってこなくなるのを防ぐ制度。原則として保全措置を講じなければ手付金等を受領できない。

  • 手付金等：契約締結日以後、引渡し前に支払われ、代金に充当される金銭（手付金・中間金など）。
  • 措置の種類：①保証委託契約（銀行等） ②保証保険契約（保険会社） ③手付金等寄託契約（指定保管機関）。未完成物件では①②のみ、完成物件は①〜③すべて可。

1. 事後届出制度

地価高騰の抑制と合理的な土地利用のため、一定の土地取引に届出を義務づける。土地売買等の契約を締結したら、権利取得者が、契約締結日から2週間以内に、市町村長を経由して都道府県知事に届出。

契約締結
→
権利取得者が2週間以内に届出（市町村長経由→知事）
→
知事は届出から3週間以内に利用目的の変更を勧告できる
→
勧告に従わない → 公表できる（契約は有効）

2. 届出が必要な契約・不要な契約

土地売買等の契約に該当する（届出必要）該当しない（届出不要）
売買（予約を含む）、交換、対価のある賃借権・地上権の設定。停止条件付き契約も該当（条件成就時の届出は不要）抵当権設定、贈与、相続、遺贈、遺産分割、時効取得、担保権実行（競売）

第3部 税・価格評定 ／ 第23章

不動産の鑑定評価、地価公示法

1. 不動産の鑑定評価

  • 同じ不動産は存在せず、個別的事情が価格に影響するため、不動産鑑定士が適正な価格を求める。
  • 価格形成要因（効用・相対的稀少性・有効需要に影響する要因）：一般的要因（災害・治安等）、地域要因（宅地エリアか農地エリアか等）、個別的要因（更地か戸建てかマンションか等）。

求める価格の4種類

価格内容
正常価格（基本）市場性を有する不動産について、合理的な条件を満たす市場で形成される市場価値（相場）
限定価格隣地の併合・分割等により市場が相対的に限定される場合の価格（例：甲土地所有者が隣の乙土地を買うときの価格。正常価格800万円の乙土地が1,200万円）
特定価格証券化対象不動産など、法令等による社会的要請を背景に、正常価格の前提条件を満たさない場合の価格
特殊価格文化財・宗教建築物など一般に市場性を有しない不動産の、利用現況を前提とした価格

鑑定評価の3手法（複数を併用するよう努める）

手法考え方ポイント
原価法再調達原価−減価修正＝積算価格減価修正は耐用年数に基づく方法と観察減価法を併用。土地のみでも再調達原価を求められれば適用可
取引事例比較法多数の事例を収集 → 事情補正・時点修正 → 比準価格事例は近隣地域または同一需給圏内の類似地域から。売り急ぎ等は事情補正、地価変動は時点修正。投機的取引は使えない
収益還元法将来の純収益の現在価値の総和＝収益価格賃貸不動産・事業用不動産に特に有効。市場性のない不動産以外には基本的にすべて適用。自己居住用住宅にも賃貸を想定して適用可。地価上昇が著しいときも適用可

2. 地価公示法

土地取引の「目安」を公表する制度。土地鑑定委員会（国土交通省に置かれる）が中心となる。

①標準地の選定土地鑑定委員会が公示区域（国交大臣が定める）内で選定
→
②鑑定2人以上の不動産鑑定士が毎年1回
→
③審査・判定委員会が審査・調整し正常な価格を判定
→
④地価公示委員会が官報で公示
→
⑤図書の送付・閲覧関係市町村長に送付し、市町村長が一般の閲覧に供する
  • 標準地の選定基準：類似の利用価値を有する地域で、利用状況・環境等が通常と認められる一団の土地。
  • 鑑定の勘案事項：①同等の効用を有する土地の造成費用 ②近傍類地の取引価格から算定される価格 ③近傍類地の地代等から算定される価格。平均するのではない。
  • 正常な価格：建物や地上権等を取り払った更地価格（自由な取引で通常成立する価格）。
  • 公示事項：所在（郡市区町村・字・地番）、単位面積当たりの価格と価格判定の基準日、地積・形状、周辺の土地の利用現況 など。
公示価格の効力内容
指標（努力義務）土地取引を行う者は、類似する標準地の公示価格を指標として取引するよう努める
規準（義務）①不動産鑑定士が公示区域内の土地の正常な価格を求めるとき ②土地収用法等で公示区域内の土地の取得価格を定めるとき → 公示価格を規準としなければならない

1. 住宅金融支援機構

民間金融機関をサポートして長期固定金利の住宅ローンを実現する（証券化支援業務）。民間が対応しにくい分野では直接融資を行う。

顧客

→
②機構が債権を買い取り
→
③証券化（MBS）して投資家に販売
  • 金利や手数料は金融機関によって異なる。
  • 買取型の対象債権：新築の建設・購入、中古住宅の購入、付随する土地・借地権の取得、親族居住用住宅、購入に付随する改良、高齢者の居住性能向上のための改良。賃貸住宅は対象外。
  • ZEH・省エネ・耐震・バリアフリー等に優れた住宅は一定期間金利引下げ。
  • 高齢者向け返済特例：毎月は利息のみ、元金は死亡時に一括返済。
  • 直接融資（例外）：①災害復興建築物の建設・購入、被災建築物の補修 ②合理的土地利用建築物の建設・購入、マンション共用部分の改良 ③子育て家庭・高齢者家庭向け賃貸住宅の建設・改良 ④高齢者が自ら居住する住宅のバリアフリー改良 ⑤60歳以上の高齢者の部分的バリアフリー・ヒートショック対策・耐震改修（高齢者向け返済特例）。
  • 団体信用生命保険業務：死亡・重度障害時の保険金を債務の弁済に充当。

土地・建物

1. 土地

宅地に適している特徴
台地平らで周囲より高い。地盤が安定し災害に強い。農地・都市的利用も多い
丘陵なだらかな起伏。台地・丘陵の縁辺部は豪雨時のがけ崩れに注意
段丘河岸・海岸の階段状地形。砂礫・硬粘土で地下水位が深い
自然堤防河川の氾濫で川の両側にできた微高地。砂・小礫で排水良好、地盤も比較的良い
宅地に適していない特徴
旧河道かつての流路。泥土で排水が悪く軟弱
後背低地（後背湿地）自然堤防の背後の低湿地。軟弱。水田利用が多い
三角州河口付近の軟弱地盤
扇状地砂礫で地盤は良好だが、谷出口は土石流の危険が高い
干拓地排水が悪く軟弱。海面より低いことが多く津波に注意
埋立地海面より高いので干拓地より安全
  • 等高線：間隔が密＝急傾斜、疎＝緩やか。乱れている部分は過去の崩壊の可能性。山頂に向かって高い方に弧を描く部分が谷、山頂から張り出す部分が尾根。
  • 地すべり地：地下水の影響で斜面が滑る。地すべり地形は棚田等の水田に利用される。
  • 液状化：地震で地下水位の高い砂地盤が液体状になる。

2. 建物

構造特徴
木造①乾燥して含水率が小さいほど強度大 ②辺材は心材より腐朽しやすく耐久性小 ③圧縮強度は繊維直角方向より繊維方向が大
・枠組壁工法（ツーバイフォー）：壁式で耐震性に優れる
・集成木材工法：ドーム・体育館など大型建築に用いる
鉄骨造（S造）不燃だが火熱で耐力が落ちるため耐火構造には耐火材料で被覆。自重が軽く靱性が大きく高層向き。炭素含有量が多いと硬く伸びが減るので炭素の少ない鋼を使う
鉄筋コンクリート造（RC造）鉄筋とコンクリートの長所を生かし短所を補う。中性化は耐久性に影響。耐火・耐久・耐震・耐風に優れる。コンクリートの引張強度は圧縮強度より小さい
鉄骨鉄筋コンクリート造（SRC造）S造の靱性＋RC造の耐火性・耐久性。RC造より靱性・強度に優れ高層建築に使用
地震対策の構造仕組み
耐震構造柱・はり・耐震壁で剛性を高めて耐える
免震構造下部構造と上部構造の間に積層ゴム等を設置して揺れを減らす
制震構造制震ダンパー等で揺れを制御
